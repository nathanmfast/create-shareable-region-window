# Create Shareable Region Window

Create Shareable Region Window turns an adjustable area of the desktop into a dedicated window that can be shared in Teams, Zoom, Meet, Discord, and other meeting applications.

The repository contains two native desktop applications side by side:

- [`windows/`](windows/) — the .NET 10 Windows Forms application.
- [`macos/`](macos/) — the Swift and ScreenCaptureKit macOS application.

Each application has platform-specific build and usage instructions in its own README.
