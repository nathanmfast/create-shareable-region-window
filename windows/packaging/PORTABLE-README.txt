Create Shareable Region Window
==============================

1. Extract this ZIP to any folder.
2. Run CreateShareableRegionWindow.exe.

No installation, administrator access, or separate .NET runtime is required.
The app saves settings.json in this folder. Keep that file to retain your settings,
or delete it to restore the defaults.

Windows may show a SmartScreen warning because this app is not code-signed. Only
run software you received from a source you trust.

Requires 64-bit Windows 10 or Windows 11.
